**Spanning Tree Protocol (STP) Network Implementation**

A Cisco Packet Tracer project demonstrating the implementation of Spanning Tree Protocol (STP) in a switched network. The topology consists of three interconnected switches forming a redundant Layer 2 loop, with STP automatically preventing broadcast storms by blocking redundant paths while maintaining network availability and fault tolerance.

****Features:****

1.Three-switch redundant topology

2.Spanning Tree Protocol (STP) configuration

3.Loop prevention mechanism

4.Automatic root bridge election

5.Redundant path management

6.Layer 2 network resilience

7.Network convergence testing

**Technologies Used**

1.Cisco Packet Tracer

2.Cisco Catalyst 2960 Switches

3.Spanning Tree Protocol (STP)

4.Ethernet Switching

5.Layer 2 Networking

6.Redundancy and Failover Concepts

**How to Run**

1.Install Cisco Packet Tracer.

2.Open the .pkt project file.

3.Verify switch interconnections.

4.Use the CLI to view STP status:

show spanning-tree

5.Observe the root bridge and blocked ports.

6.Disconnect a link to test STP failover and network convergence.

**Learning Outcomes**

1.Understanding Spanning Tree Protocol

2.Preventing switching loops

3.Root bridge election process

4.Redundant network design

5.Network fault tolerance and recovery
